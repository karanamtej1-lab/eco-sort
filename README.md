# Eco-Sort

Point your phone's camera at an item of trash and Eco-Sort tells you whether it goes in **Recycling**, **Compost**, or **Landfill**, live, in the browser.

**Live:** https://karanamtej1-lab.github.io/eco-sort/

- Image classifier trained with [Google Teachable Machine](https://teachablemachine.withgoogle.com/), run with TensorFlow.js
- Plain HTML, CSS and JavaScript, with no build step
- Runs entirely on your device: no images are uploaded
